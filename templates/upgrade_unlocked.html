DIY Fix Guide

What to change.

{% if bd.parseability < bd.parseability_max %}

1. Fix the parsing issues first

These are the highest-impact fixes. ATS parsers fail before they ever get to your content if the file format itself is breaking. Common fixes: remove text boxes and convert their content to body text; replace tables with bulleted lists; use a single-column layout; export from Word as plain PDF rather than image-flattened.

{% endif %} {% if bd.structure < bd.structure_max %}

2. Fix the structure

Use clear section headers — exactly the words "Experience", "Education", and "Skills". Put your contact details (email and phone) in the body of the document, not in the header/footer area, where ATS systems often skip. Make sure each role has start and end years ({{ scan.region }} convention: full year for both).

{% endif %} {% if bd.keywords < bd.keywords_max and result.missing_keywords %}

3. Integrate missing keywords

Don't just paste them in — that makes the CV read poorly to humans. Instead, find places in your existing experience where you legitimately used these skills, and rephrase your bullets to include the term. Example: "Managed projects" → "Led cross-functional projects through agile methodology, coordinating with stakeholders across engineering and finance" (uses "agile methodology" and "stakeholders" naturally).

{% endif %} {% if bd.content < bd.content_max %}

4. Strengthen the writing

Lead each bullet with a strong action verb (Led, Managed, Drove, Delivered, Implemented). Add at least one quantified achievement per role: percentages, currency amounts, headcounts, time savings — anything that converts "I did X" to "I did X, with this measurable result". Drop the personal pronouns; CVs conventionally start bullets with the verb directly.

{% endif %}
